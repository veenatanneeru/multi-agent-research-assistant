# Multi-Agent Research Assistant

Enterprise-style multi-agent research assistant built with **LangGraph**, **FastAPI**, **MCP**, **RAG**, and local **LLMs via Ollama**.

Given a research question, a small team of agents plans sub-questions, researches
them on the web, and synthesizes the findings into a structured report — no
external API keys required (runs entirely on a local Ollama model).
